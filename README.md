# BMO-V2

Desktop assistant integrado com nanobot, voz local, canais e uma interface Electron + React.

## Estrutura

- `backend/` - API local em Python
- `ui/` - frontend React
- `electron/` - shell desktop
- `bridge/` - ponte WhatsApp
- `nanobot/` - motor de agente vendorizado
- `runtime/` - ativos grandes nao versionados
